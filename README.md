# Advisory Firm Website

Five-page English marketing site for a fictional consulting firm.

**Demo project.** All businesses, products, people and numbers are fictional. Nothing is sent anywhere and no real data is collected.

## What it does
- Home, About, Services, Insights, Contact pages with current-page navigation
- Contact form with validation (name, email, message) and a demo confirmation
- Responsive layout checked at 390px and 1280px

## Run it
No build step. Open `index.html` in a browser, or serve the folder: `python3 -m http.server 8000`.

## Stack
HTML, CSS and plain JavaScript. No frameworks.
